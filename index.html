    About

    Interval Runner

    Compose and run timed interval workouts with audio cues. Design your workout, press Run, pocket the phone, and listen through earphones while running.

    Each workout is built from timed blocks and repeating groups. During execution, the app speaks the block text aloud and counts down the timer, so you can focus on your run without checking the screen.

    Editor Help

    Creating a Workout

    A workout is made of blocks and groups.

    Blocks are timed segments. Each block has speech text (spoken aloud when the block starts), a duration in seconds, and a repeat count.

    Groups are containers that hold blocks and repeat all their children N times. Use groups for sets of intervals you want to cycle through.

    Sound Tokens

    Regular text in a block is spoken aloud using the SAM speech synthesizer. You can also embed sound tokens anywhere in the text to play tones and beeps:

    TokenSoundUse for
    *Short beep (200ms)Tick / count
    **Medium beep (400ms)Attention
    ***Long beep (700ms)Start / end
    ^Rising tone (400ms)Get ready / ramp up
    vFalling tone (400ms)Rest / wind down
    !Buzzer (300ms)Alert / stop

    Tokens can be placed inline with no spaces needed.

    Example: Ready*set***go → speaks "Ready" → short beep → speaks "set" → long beep → speaks "go"

    Example: Sprint! → speaks "Sprint" → buzzer

    Example: ^^Run → two rising tones → speaks "Run"

    Loop Variables

    Groups can be assigned a single-letter variable (a–z) using the Var input next to the repeat count. This letter can then be referenced in leaf text to show the current iteration number.

    SyntaxMeaningExample (5 reps)
    {a}Current iteration (count up)1, 2, 3, 4, 5
    {#a}Total iterations5, 5, 5, 5, 5
    {%a}Countdown5, 4, 3, 2, 1
    {~a}Remaining after current4, 3, 2, 1, (empty)

    Example: A group with letter r and repeat 5, containing a leaf with text Round {r} of {#r}***go → speaks "Round 1 of 5" → long beep → speaks "go" on first iteration.

    Variables from outer groups are available in inner blocks. If a letter is not defined in any ancestor group, it is left as-is.

    Sound Preview

    Each block in the editor has a ♪ button that lets you preview how the text sounds. Variables are substituted assuming iteration 1 for all groups.

    Voice Engine

    Choose your voice on the home screen:

    SAM — Instant, robotic voice. No download needed. Works offline immediately.

    HD Female / HD Male — Natural-sounding neural voice powered by Piper. Requires a one-time ~60 MB download per voice. Once loaded, works offline.
